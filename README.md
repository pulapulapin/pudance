# PuDance

Local dance practice room — import a clip, slow it down, mirror, loop, follow along.

- Website: https://pulapulapin.github.io/pudance/
- **Report a bug:** [open an issue](https://github.com/pulapulapin/pudance/issues/new?template=bug_report.yml)

This repository contains the PuDance website and its bug tracker only. The app itself is not open source.
