隐私政策

最后更新：2026-10-17

一句话

PuDance 在你的设备上完成工作。没有账号、没有统计、没有广告、没有向我们上报的崩溃日志。我们不收集、不接收、也不上传你的练习视频。在 App Store 上，隐私标签为「不收集数据」。

你的数据在哪里

数据位置说明
导入的练习视频 / Pack该设备上的应用沙盒只在该设备
跟拍录像（若使用）应用沙盒，或你保存到的相册只在该设备
设置（默认静音等）设备上的应用偏好只在该设备

什么时候会联网

只在你或系统做了某件事之后：

  • 从 App Store / TestFlight 安装或更新（由 Apple 处理）。
  • 购买或恢复内购：付款由 Apple 处理，PuDance 只知道购买是否有效。
  • 打开本网站或在 GitHub 提交 Issue（常规网页 / GitHub 流量）。

PuDance 不会把舞蹈视频发到我们的服务器。我们没有用户内容同步服务器。

相机、麦克风与相册

相机与麦克风仅用于可选的跟拍预览 / 录制。相册 / 文件权限仅用于你选择导入视频。系统权限框会说明用途。你可以拒绝授权；依赖该权限的功能将不可用。

购买

App Store 的付款、收据与退款由 Apple 按其隐私政策处理。

你的选择

  • 可在应用内删除 Pack 与录像，或删除应用以清除沙盒数据。
  • 可在系统设置中撤销相机 / 相册权限。

变更与联系

本政策有变化时，上面的日期会同步更新。问题或 Bug 反馈：GitHub Issues / 839200644@qq.com。
