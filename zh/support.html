PuDance 支持

使用说明，以及如何反馈 Bug。

系统要求

  • iPhone / iPad，iOS 15 或更高（TestFlight / App Store）。
  • Mac 开发构建可用；Mac 商店上架稍后。
  • 本机已有、且你有权用于练习的舞蹈视频。

快速上手

  1. 通过 TestFlight 或日后的 App Store 安装 PuDance。
  2. 导入或跟拍时按提示授权相册 / 相机。
  3. 用参考片创建一个 Pack。
  4. 用慢放、镜面、循环抠练。
  5. 可选：打开跟拍，对照参考片录一条——只保存在本机。

能做什么、不能做什么

能不能
导入本地 / 相册视频练习从网页下载舞蹈或去水印
慢放、镜面、AB 循环、跟拍相机把视频上传到广场或社交流
Pack 与 takes 保存在本机跨设备同步练习库（暂无）
端上处理视频绕过 DRM 或访问私有流

常见问题

会上传我的视频吗？

不会。练习片和跟拍都在本机。详见隐私政策。

需要账号吗？

不需要。

Pack 存在哪里？

该设备上的应用本地存储。

App Store 购买怎么退款？

由 Apple 处理，见 reportaproblem.apple.com。

能练有版权的编舞吗？

请只导入你有权用于个人练习的视频。PuDance 不提供第三方内容的下载或传播。

反馈 Bug

本 GitHub 仓库是支持渠道。请尽量提供：

  • 你做了什么、期望什么、实际发生了什么。
  • 机型、iOS / macOS 版本、PuDance 版本（设置页）。
  • 问题出在导入、播放、镜面/慢放/循环，还是跟拍。
